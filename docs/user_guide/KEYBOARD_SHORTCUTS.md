# Keyboard Shortcuts

## Navigation

- `Ctrl+O`: Open folder
- `Ctrl+L`: Edit the active pane's path in the breadcrumb (Enter navigates, Esc cancels)
- `Backspace`: Go to parent folder from the file pane
- `F5`: Refresh current view
- `Esc`: Clear file selection

## File Operations

- `Ctrl+C`: Copy selected files
- `Ctrl+X`: Cut selected files
- `Ctrl+V`: Paste into current folder
- `Delete`: Move selected files to trash
- `F2`: Rename selected file
- `Ctrl+Shift+C`: Copy the selection into the other pane's folder (second pane on)
- `Ctrl+Shift+M`: Move the selection into the other pane's folder (second pane on)

## Selection

- `Ctrl+A`: Select all visible files
- `Ctrl+Click`: Toggle file selection
- `Shift+Click`: Select a range

## View and Preview

- `,`: Step backward in video/sequence preview
- `.`: Step forward in video/sequence preview
- `Ctrl+Q`: Quit the application

## Other

- `Ctrl+Shift+N`: New folder
- `Ctrl+Z` / `Ctrl+Y`: Undo / redo file operation
- `Shift+Delete`: Delete permanently (with confirmation)
- `Alt+Left` / `Alt+Right`: Back / forward in folder history
- `Space`: Open the focused / selected item in the viewer
- `Ctrl+P`: Show / hide the preview pane
- `F1`: Show the shortcuts list
- `F3`: Show / hide the second file pane
- `Tab`: Switch the active pane (the folder tree navigates the active pane)
- `Arrows`, `Home`, `End`, `PageUp`, `PageDown`: Move focus in the file pane (`Shift` extends the selection)
- `Enter`: Open folder / open the fullscreen viewer

## Viewer (fills the main window)

- `Esc`: Close the viewer (back to the browser)
- `Left` / `Right` or `PageUp` / `PageDown`: Previous / next item
- `Space`: Play / pause
- `,` / `.`: Step one frame backward / forward
- `F`: Toggle OS fullscreen (closing the viewer restores the previous window state)
- `0`: Fit to window
- `1`: Actual size (100%)
- `+` / `-`: Zoom in / out
