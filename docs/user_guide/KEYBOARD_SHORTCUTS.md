# Keyboard Shortcuts

## Navigation

- `Ctrl+O`: Open folder
- `Backspace`: Go to parent folder from the file pane
- `F5`: Refresh current view
- `Esc`: Clear file selection

## File Operations

- `Ctrl+C`: Copy selected files
- `Ctrl+X`: Cut selected files
- `Ctrl+V`: Paste into current folder
- `Delete`: Move selected files to trash
- `F2`: Rename selected file

## Selection

- `Ctrl+A`: Select all visible files
- `Ctrl+Click`: Toggle file selection
- `Shift+Click`: Select a range

## View and Preview

- `,`: Step backward in video/sequence preview
- `.`: Step forward in video/sequence preview
- `Ctrl+Q`: Quit the application
